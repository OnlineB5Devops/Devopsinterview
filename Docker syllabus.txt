### Phase 3 — Dockerfile ⭐ Very Important

Learn every major Dockerfile instruction:

```dockerfile
FROM
RUN
CMD
ENTRYPOINT
COPY
ADD
WORKDIR
ENV
ARG
EXPOSE
USER
VOLUME
LABEL
```

Example:

```dockerfile
FROM nginx:latest

WORKDIR /usr/share/nginx/html

COPY index.html .

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

Understand especially:

**CMD vs ENTRYPOINT**  
**COPY vs ADD**  
**ARG vs ENV**  
**RUN vs CMD**

These are common interview questions.

## Phase 5 — Docker Storage

- Container writable layer

- Bind mounts
- tmpfs
- Persistent data

Commands:

```bash

```


# Phase 10 — Docker Logging & Troubleshooting ⭐⭐⭐

This is extremely important for your **SRE/DevOps background**.

Learn:

```bash
docker logs
docker inspect
docker stats
docker events
docker top
docker exec
```

Troubleshooting scenarios:

### Scenario 1
Container is running but application is inaccessible.

Check:

```bash
docker ps
docker logs <container>
docker inspect <container>
```

Then check:

```text
Port mapping
Application port
Firewall
Application logs
Network
```

### Scenario 2
Container continuously restarting.

Check:

```bash
docker ps -a
docker logs <container>
docker inspect <container>
```

### Scenario 3
Container exits immediately.

Understand:

```bash
docker ps -a
docker logs <container>
```

and the difference between:

```text
Running container
Exited container
Restarting container
```

## 🧠 Daily Study Pattern

Since you're preparing for a **DevOps/SRE job**, don't spend the whole day watching courses.

Use this approach:

**1 hour — Learn**

**1 hour — Hands-on**

**30 minutes — Troubleshooting**

**30 minutes — Interview preparation**

So approximately:

```text
           4 Hours/day

      ┌─────────────────┐
      │ Theory — 1 hour  │
      ├─────────────────┤
      │ Practice — 1 hr  │
      ├─────────────────┤
      │ Troubleshooting  │
      │      — 30 min    │
      ├─────────────────┤
      │ Interview — 30m  │
      └─────────────────┘
```

### Most important advice

Don't try to memorize 100 Docker commands.

You should be able to **build an image, run an application, connect containers, persist data, troubleshoot failures, push the image to a registry, and automate the entire process through Jenkins.**

That is much closer to what you'll actually be expected to do in a DevOps/SRE role.
